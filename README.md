## Nodepp-UIKIT
**Nodepp-UIKIT** is a lightweight, NOJS CSS framework engineered for simplicity.

```
<head><meta charset="UTF-8">
        
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <link rel="stylesheet" href="https://raw.githubusercontent.com/NodeppOfficial/nodepp-css-uikit/refs/heads/main/www/uikit.css">
    <title> Document </title>

</head>
```
